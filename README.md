# Vaja Karan - Cybersecurity Portfolio

A modern, responsive cybersecurity portfolio website built with Flask, Python, HTML, CSS, and JavaScript.

## Features

- 🛡️ Cyber/neo aesthetic with dark theme
- 💫 Matrix rain animation
- 🎯 Glitch text effects
- 📱 Fully responsive design
- ✉️ Contact form with email integration
- 💬 WhatsApp booking integration
- 🔍 Project filtering
- 🎨 Animated skill cards
- 📊 Interactive progress bars
- 🏆 Certification showcase

## Technology Stack

- **Backend**: Python, Flask
- **Frontend**: HTML, CSS, JavaScript
- **Email**: Flask-Mail (Gmail SMTP)
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Orbitron, Rajdhani)
